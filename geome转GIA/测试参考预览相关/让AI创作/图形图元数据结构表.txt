图形图元数据结构表
数据格式：JSON 数组，每元素 = 一个图元对象，字段含义如下。
{ "type": 类型编号, "data": [坐标数据], "color": [R,G,B,A], "score": 置信度, "params": [归一化参数, 仅等腰三角有] }
统一归一化表示：任意图元均可推导为 params = [Cx, Cy, W, H, Rot]，即中心(Cx,Cy)、宽 W、高 H、旋转角 Rot（度，顺时针为正）。坐标系：原点在图像左上角，X 向右、Y 向下。
type	名称	data 参数 [ ]			中心坐标 (Cx, Cy)		宽 / 高 (W, H)			旋转 Rot / 备注
0	矩形	[X1, Y1, X2, Y2]  左上角、右下角坐标	((X1+X2)/2, (Y1+Y2)/2)	W = X2 - X1，H = Y2 - Y1		Rot = 0（无旋转）
1	旋转矩形	[X1, Y1, X2, Y2, Rot]  左上角、右下角 + 角度 ((X1+X2)/2,  (Y1+Y2)/2)	W = X2 - X1，H = Y2 - Y1		Rot 为旋转角（度） 顺时针为正
3	椭圆	[X, Y, RX, RY] 圆心、X/Y 半径		(X, Y)			W = RX × 2    H = RY × 2		Rot = 0（无旋转） 
4	旋转椭圆	[X, Y, RX, RY, Rot] 圆心、X/Y半径、角度	(X, Y)			W = RX × 2 H = RY × 2		Rot 为旋转角（度）
5	圆	[X, Y, R] 圆心、半径			(X, Y)			W = R × 2 H = R × 2		Rot = 0 
6	线段	[X1, Y1, X2, Y2] 起点 → 终点	((X1+X2)/2, (Y1+Y2)/2)	 L = √(dx²+dy²)宽/高自定义   		Rot = atan2(dx, dy)  dx=X2-X1, dy=Y2-Y1（弧度→度，负角+360°）
8	等腰三角形	data: [X1,Y1,X2,Y2,X3,Y3] 三顶点 params: [Cx,Cy,W,H,Rot] 高中心/底/高/角	(Cx, Cy) 即高的中点	W = 底长 H = 高	Rot 为高方向的旋转角（度） 三角形顶点朝上时 Rot = 0
备注：① type=2/7 在当前数据集未定义，保留编号；② 矩形/椭圆/圆无旋转时 Rot 统一记 0；
③ 线段（type=6）的旋转角用 atan2(dx, dy) 计算，结果映射到 [0°, 360°)，表示从起
  点指向终点的方向；④ 等腰三角（type=8）data 存三顶点坐标，params 存归一化参数。
