你是一位矢量图形创作专家。请用基础几何图元创作一幅卡通画，并以指定 JSON 格式输出。‌

‌一、画布与坐标系‌

    画布尺寸：512 × 512 像素
    坐标系原点在左上角，X 向右、Y 向下
    所有坐标均为像素值（整数或浮点数均可）

‌二、图元总数限制‌

    图元总数不超过 1000 个，鼓励精简构图

‌三、创作要求‌

    主题：一只可爱的卡通小猫站在草地上，背景有蓝天和太阳
    风格：扁平化卡通风格，色彩明快，线条简洁
    必须使用以下基础图元组合完成，不得使用其他类型

‌四、可用图元类型与数据格式‌
表格
type 	名称 	data 数组格式 	说明
0 	矩形 	[X1, Y1, X2, Y2] 	左上角、右下角坐标，无旋转
1 	旋转矩形 	[X1, Y1, X2, Y2, Rot] 	左上角、右下角 + 旋转角度（度，顺时针为正）
3 	椭圆 	[X, Y, RX, RY] 	圆心坐标、X 半径、Y 半径，无旋转
4 	旋转椭圆 	[X, Y, RX, RY, Rot] 	圆心、半径、旋转角度
5 	圆 	[X, Y, R] 	圆心坐标、半径
6 	线段 	[X1, Y1, X2, Y2] 	起点到终点
8 	等腰三角形 	[X1, Y1, X2, Y2, X3, Y3] 	三个顶点坐标

‌注意：type=2 和 type=7 未定义，禁止使用。‌

‌五、每个图元对象的完整字段‌

json
{
  "type": 类型编号,
  "data": [坐标数据数组],
  "color": [R, G, B, A],
  "score": 0.99,
  "params": [Cx, Cy, W, H, Rot]
}

    color：RGBA 颜色，取值范围 0-255，A=255 表示完全不透明
    score：置信度，统一填 0.99 即可
    params：归一化参数 = [中心X, 中心Y, 宽度, 高度, 旋转角]
        矩形/椭圆/圆无旋转时 Rot 填 0
        线段的旋转角用 atan2(dx, dy) 计算，映射到 [0°, 360°)
        等腰三角形的 params 为 [高的中点X, 高的中点Y, 底长, 高, 高方向旋转角]，顶点朝上时 Rot=0

‌六、输出要求‌

    只输出一个 JSON 数组，数组中每个元素是一个图元对象
    不要输出任何解释文字、markdown 标记或代码块包裹
    直接输出纯 JSON 文本
